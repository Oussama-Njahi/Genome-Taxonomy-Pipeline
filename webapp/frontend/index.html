Taxo Genomics Analyses, in one run!

Upload a set of bacterial genome assemblies and get a complete taxonomic profile in return: genome quality with CheckM2, pairwise identity across ANI, dDDH, AAI and POCP, and a phylogenomic tree built with FastANI, BLASTN, EzAAI, DIAMOND and EasyCGTree. Results come with ready-to-read heatmaps and a tree figure, not just raw numbers.
Every step is optional: pick exactly the analyses you need.

How it works

Every step below is independent — use the checkboxes on the Analyze page to run exactly the ones you need. Two steps expect another one to have run first: CheckM2 needs Quality Control, and POCP needs Protein prediction — skip them and that one step is skipped too, with a clear warning, the rest of your selection still runs.

01 Quality Control Genome size, GC% and contig count for each assembly.
02 CheckM2 Estimates completeness and contamination from marker genes. Needs Quality Control to have run first
03 Protein prediction Predicts genes and proteins from each genome with Prodigal.
04 ANI Whole-genome DNA similarity between every pair, via FastANI.
05 dDDH In-silico DNA-DNA hybridization estimate from BLASTN alignments.
06 AAI Average amino-acid identity between proteomes, via EzAAI.
07 POCP Share of conserved proteins between genomes, via DIAMOND. Needs Protein prediction to have run first
08 Phylogenomic tree Evolutionary tree built from shared marker genes with EasyCGTree.
09 Figures Heatmaps and a tree plot summarizing all the results.
